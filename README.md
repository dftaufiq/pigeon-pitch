One line: the elevator pitch a city pigeon gives investors for its homing-pigeon package-delivery startup.

> My startup, Homing, delivers packages by pigeon — 4,000 years of never getting lost, zero fuel, and our only delay is a statue that looked like lunch.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`) and prints it
to stdout. The line is 150 characters — inside the 200-character cap.
